# かんたん動画編集

Chrome で開くだけで使える動画編集ソフトです。インストールもサーバーも不要です。
読み込んだ動画・画像・音楽は**パソコン（ブラウザ）の中だけで処理され、どこにも送られません。**

公開ページ: https://koduck110-png.github.io/video-editor/

## できること

**段階1（基本）**
- 動画・画像・音楽の読み込み（ドラッグ＆ドロップ／「ファイルを読み込む」ボタン）
- タイムライン（映像・文字・音声トラック）：並べる・ドラッグで移動・端をつまんで長さ変更・分割・削除・拡大縮小
  - 同じ時間に重ねると段（トラック）が自動で増える（映像は上の段が手前に表示）
- プレビュー（再生・一時停止・好きな位置へ移動）
- 書き出し：MP4（音声付き）をダウンロード
- 元に戻す・やり直し（Ctrl+Z / Ctrl+Y）

**段階2（CapCut の基本編集）**
- 画面比率（16:9・9:16 縦動画・1:1・4:5・4:3・3:4・21:9）と背景（色・ぼかし）
- 位置・大きさ・回転・不透明度・反転（プレビューの絵を直接ドラッグして操作できる。ワイプも作れる）
- 音量・ミュート・フェードイン/アウト・音声の分離
- 速度変更（0.1〜10倍）
- フィルター（15種類・強さ調整）と色の調整（明るさ・コントラスト・彩度・色温度・色合い・ビネット）
- トランジション（クロスフェード・暗転・スライド・ワイプ・円形・ズーム・ぼかし など11種類）
- アニメーション（入り・出：フェード・ズーム・スライド・ポップ・回転・ぼかし・タイプ）
- 文字：フォント（Google Fonts 15種類）・太字/斜体・揃え・間隔・縁取り・背景・影・デザインのひな形
- コピー・貼り付け・複製（Ctrl+C / Ctrl+V / Ctrl+D）、右クリックメニュー
- 自動保存（ブラウザの中に保存。開き直すと続きから）・新規プロジェクト
- 書き出し設定（720p〜4K、24〜60コマ/秒、画質）

## キーボード操作

| キー | 動作 |
| --- | --- |
| スペース | 再生・一時停止 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+B | 分割 |
| Ctrl+C / Ctrl+V / Ctrl+D | コピー / 貼り付け / 複製 |
| Delete | 選んだクリップを削除 |
| ← / → | 1コマ移動（Shift で1秒） |
| Ctrl+マウスホイール | タイムラインの拡大・縮小 |

## 開発者向け

```bash
npm install
npm run dev        # 開発用サーバー
npm run build      # dist/ に組み立て
npm run test:e2e   # 組み立て後、実際のブラウザで操作して確認（tests/e2e.mjs と tests/e2e-stage2.mjs）
```

- Vite + React + TypeScript
- 書き出しは WebCodecs + [Mediabunny](https://mediabunny.dev/)（H.264 / AAC。ブラウザが AAC を作れない場合は `@mediabunny/aac-encoder` を使用）
- 作業内容と素材ファイルはブラウザの IndexedDB に保存（外部には送らない）。文字のフォントだけ Google Fonts から読み込む
- `main` ブランチに push すると GitHub Actions が GitHub Pages へ公開します（`.github/workflows/deploy.yml`）
- `npm run test:e2e` で H.264 / AAC を確かめるには、Google Chrome（または Chrome for Testing）の場所を `CHROME_PATH` で指定してください。指定しない場合は Playwright の Chromium で VP9 / Opus の代わりの形式を確かめます。
